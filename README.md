# Qual parte do Espiritismo você não entendeu? — Landing Page Oficial

Landing page editorial desenvolvida com **React**, **Vite**, **Tailwind CSS** e **HTML5** para a obra *"Qual parte do Espiritismo você não entendeu? — Respostas simples para grandes perguntas da alma"*, de **Geraldo Corrêa de Lyra Junior** (Scortecci Editora).

Link oficial da obra na editora: https://www.scorteccilivraria.com.br/produto/qual-parte-do-espiritismo-voce-nao-entendeu

## Como Executar Localmente

```bash
npm install
npm run dev
```
